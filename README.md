# Cupcake Ordering System — PI II

Projeto desenvolvido para a disciplina de **Projeto Integrador Transdisciplinar II em Engenharia de Software**.

## Sobre o projeto

O Cupcake App é uma aplicação web desenvolvida para uma loja de cupcakes, com o objetivo de disponibilizar uma vitrine virtual e permitir que clientes realizem pedidos, selecionem formas de pagamento e acompanhem o status de suas entregas.

O projeto dá continuidade à proposta desenvolvida no Projeto Integrador Transdisciplinar I (PI I), na qual foram levantados e organizados os requisitos da solução.

## Objetivo

Desenvolver uma aplicação funcional que permita a gestão do catálogo de cupcakes e a realização e acompanhamento de pedidos pelos clientes.

## Funcionalidades

### Cliente

- Visualizar catálogo de cupcakes;
- Visualizar detalhes dos produtos;
- Adicionar produtos ao carrinho;
- Alterar quantidades;
- Remover produtos do carrinho;
- Visualizar o valor total da compra;
- Informar dados de entrega;
- Selecionar forma de pagamento;
- Confirmar pedidos;
- Consultar o status dos pedidos.

### Administrador

- Cadastrar produtos;
- Editar produtos;
- Desativar produtos;
- Visualizar pedidos;
- Consultar detalhes dos pedidos;
- Atualizar o status dos pedidos.
